## 接入时要知道的事

1. **压缩格式**：Meshopt 加 WebP 贴图。drei 的 `useGLTF` 默认带 Meshopt 解码器，不用额外配置。不要用 Draco 解码器。
2. **尺寸**：Tripo 把每个模型的最长边归一到约 1 个单位，所以各模型之间的比例是错的。接入时按真实高度乘以 PRD 规定的 2 到 3 倍放大来定缩放，并统一用同一个放大倍数。
3. **原点**：底面在 Y 等于 0，水平方向大致居中。直接放在 `lngLatToScene` 加 `terrainY` 算出的位置即可。
4. **朝向没有统一**：断桥的长轴沿 X，花港观鱼的长轴沿 Z。断桥要转到与白堤走向一致，其余按湖岸方向逐个调。
5. **三潭印月**：`landmarks.json` 里写的是一个 `santan.glb`，实际是两个文件。亭子放在小瀛洲岛上，石塔复制三座放在岛南的水面上，呈三角形排列。
6. **颜色要往色板上拉**：参考图的柱子和栏杆是高饱和的朱红，比定稿图2 鲜艳得多，直接放进青绿山水里会跳。接入时在材质上统一降低饱和度，把红色压向 PRD 的低饱和朱红。所有景点共用同一套调色，不要逐个调。
7. **材质**：统一粗糙度，金属度设为 0。文件里带一个 `KHR_materials_volume` 扩展，没有实际作用，可以忽略。
8. **夜晚发光**：按 PRD 第 6.4 节，由代码统一加暖色自发光和辉光光点，强度从 `uNight` 插值。
9. **去光处理**：生成时已开启 Tripo 的去光选项。接入后在白天和夜晚各看一眼，如果某个模型贴图里仍有明显的固定阴影，记下来反馈。

## 贴图

- `assets-raw/textures/paper.png`：宣纸纹理，可用。很淡，平铺无明显接缝。
- `assets-raw/textures/brush.png`：**不建议使用**。图像模型把它画成了一幅水墨群山，平铺后是一排排重复的小山头，贴到地形上会在山上再画出小山。地形现有的程序化笔触继续用。

## 重新生成

原始文件在 `assets-raw/tripo/`（不入库）。替换或新增模型后运行：

```bash
sh pipeline/clean_models.sh
```

岳王庙的墙是红色的，这是有意保留的例外，调色时同样压到低饱和朱红，不要压成白墙。
